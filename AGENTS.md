# SiliconForest m1n1 maintenance

This is iconidentify's personal downstream fork. Its owner explicitly authorizes
AI-assisted research, review, integration and development. This policy replaces
the inherited upstream agent policy here. Do not send upstream issues, comments
or pull requests without explicit owner instructions.

Preserve original authorship, licenses and source provenance. Add
`Generated-by: LLM` to newly generated commits. Record exact source revisions,
firmware contracts and validation limits. A successful cross-build or host test
does not qualify a board, firmware version or boot chain. Do not install boot
components, alter boot policy, flash firmware or reboot hardware as a side effect
of building or reviewing source.

Review source visibility and licensing before publishing. Push only explicit
reviewed refs; never mirror an entire research checkout.
